# 제철 검색 달력

네이버 데이터랩 검색어 트렌드(달 단위)로, 농수산물 품목을 사람들이 몇 월에 많이 찾는지 보는 달력입니다.

- 달을 고르면 그 달 기준으로 품목이 넷으로 나뉩니다: 지금 올리면 좋아요 · 지금이 한창 · 아직 팔려요 · 철 아님.
- 품목을 누르면 작년 1년 흐름, 올해는 작년보다 더 찾는지, 올릴 때 · 내릴 때가 나옵니다.
- '찾는 양'은 사람 수가 아니라 비율입니다(귤을 제일 많이 찾은 달 = 100). 판매량 · 값은 이 자료에 없습니다.

자료: 네이버 데이터랩 검색어 트렌드, 2024-11 ~ 2026-10. 화면은 글꼴(IBM Plex Sans KR, OFL) 말고는 바깥 자원을 쓰지 않습니다.
